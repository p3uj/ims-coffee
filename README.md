# IMS - Coffee

A modern Inventory Management System (IMS) for a coffee business.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Node.js >= 20.0
- PostgreSQL >= 16

## Getting Started

Follow the steps below to run this project locally on your machine.

1. Clone the repo

   ```bash
   git clone https://github.com/p3uj/ims-coffee.git
   ```

   Navigate into the project directory:

   ```bash
   cd ims-coffee
   ```
