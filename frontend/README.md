## Frontend Setup

1. Navigate to frontend folder

   ```bash
   cd frontend
   ```

2. Install frontend dependencies

   ```bash
   npm install
   ```

3. Copy `env.example` to `env.local` and update the variables for your local environment

   ```bash
   cp .env.example .env.local
   ```

4. Run frontend development server
   ```bash
   npm run dev
   ```
